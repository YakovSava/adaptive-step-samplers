# Adaptive Samplers

ComfyUI-лан ик шонмаш йыр ыштыме сэмплер-влак: шуко ошкылан «предиктор — корректор» схемыште ончылгоч каласыме да тӧрлатыме вийысе ойыртем верысе йоҥылышым аклымаш лиеш, да тудо **эше ик сеть кычкырмаште ок шокто (ноль)** — вет тӧрлатымашым пуышо кычкырма вес ошкылланат баке кӱлеш.

Пакет тиде акым тӱжвак луктеш да, эн пайдалыже, SA-Solver-ын стохастик вийым почеш, кудыжым ComfyUI пеҥгыдын петырен шогалта.

## Шындымаш (Установка)

`ComfyUI/custom_nodes/` ужашыш клонлаш да ComfyUI-м угыч колташ. Ешартыш кӱлешлык уке: ComfyUI-н шке кӱлеш `torch`, `numpy` да `safetensors` пайдаланылтыт.

## Нодо-влак

| Нода | Лекмаш | Тӱҥ шонымаш |
| --- | --- | --- |
| `Adaptive SA Sampler` | `SAMPLER` | Почылтшо стохастик вий (`eta`) да йӱк тӧрза чек дене SA-Solver |
| `Adaptive PC Sampler` | `SAMPLER` | Йоҥылышым яра аклыше Адамсын детерминированный предиктор-корректоржо |

`asa_fixed`, `asa_adaptive`, `apc_2`, `apc_3`, `apc_2_pred`, `apc_2_fixed`, `apc_3_fixed`.

## Эн тӱҥжӧ: стохастик вий

ComfyUI кӧргыштӧ `sa_solver` лӱман SA-Solver уло (Xue et al., NeurIPS 2023). Тудо Адамсын шуко ошкылан предиктор-корректоржым **дрейфлан** гына кучылтеш, диффузий ужашым посна толалта да **ик ошкыллан лач 1 NFE** накландара. ComfyUI тудым `tau_func=None` дене кычкыра, сандене стохастик вий 20–80 % тӧрза кӧргыштӧ `eta = 1.0` дене пеҥгыдемдыме. Тудым вашталтыше нода уке.

`Adaptive SA Sampler` тудым почеш. `eta = 1.0`, `response = 0.0` да `0.2–0.8` тӧрза дене тудо `sa_solver`-ым бит дене шындарен пашам ышта (тергыме: эн кугу ойыртем `0.000e+00`).

### Висыме койыш-шоныш

Anima (flow matching DiT), 768×1024, cfg 5.0, `normal` радамлык, 10 NFE, 4 промпт × 2 сид.
*Геометрий* — 8× пулинг дене чаркым иземдыме деч вара 100 ошкыл дене `euler` эталон деч кораҥмаш;
*текстура* — кӱшыл чаркан кодшын вийже. 30 ошкылышто пырля чумыргышо SDE `0.3335` текстурым пуа.

| Сэмплер | Геометрий (шагалрак — сайрак) | Текстура |
| --- | --- | --- |
| `euler` (ODE) | 0.3677 | 0.1368 |
| `euler_ancestral` (дрейф тӧрлатыше деч посна SDE) | 0.4016 | 0.1318 |
| `sa_solver` (SDE + дрейф тӧрлатыше) | **0.3516** | **0.2244** |

Дрейф тӧрлатыше стохастик сэмплерлан детерминированный решатель деч тиде бюджет дене макро-геометрийжым *сайракым* пуа, тыгодым микрорельефым 64 % шукырак арала.

### `eta`-м ойырымаш

| `eta` | Геометрий | Текстура | Ойыртем петыралтын |
| --- | --- | --- | --- |
| 1.0 | 0.3516 | 0.2244 | 0 % |
| 1.4 | 0.3865 | 0.2503 | 24 % |
| **1.8** | **0.4225** | **0.2885** | **59 %** |
| 2.0 | 0.4541 | 0.2975 | 67 % |

Йомышо геометрий иктык олде мыняр текстура налалтеш: `0.74` — 1.0→1.4 деке куснымаште, `1.06` — 1.4→1.8 деке, `0.28` — 1.8→2.0 деке. 1.8 деч вара вашталтыш курс волгалт возеш, а изи ужаш-влак (шинчаӱп, лышташ тӱр) шекланыдыме кудыныш савырналтыт. **Паша радам — 1.6–1.8.**

`eta` кушмо семын сӱретын чоҥалтмыжат (композицийжат) вашталтеш, ӱмбал ужаш гына огыл: сайрак рашлык дене тудо сӱретым огыл, а вес сӱретым вучыза.

### Йӱк тӧрзам кугемдаш ок йӧрӧ

`stochastic_start`/`stochastic_end`-ым `0.2–0.8` гыч `0.1–0.9` деке сдвигатлымаш макро-геометрийын 20 %-жым йомдара да текстурым **совсем** ок пу (0.2244 → 0.2225). Вара `0.05–0.95` марте кугемдымаш нимом ок вашталте. Пеш кӱкшӧ sigma дене пурталтыше йӱк структуро лийын шуктымеш мӧҥгеш интегратлалтеш; пеш лыжга sigma дене йӱклан кодшо ошкыл шагал кодеш. Стохастикым рашлыкыш покшел ужаш гына савыра.

## Trajectory Probe

Кеч-могай `SAMPLER`-ым авызла да кажне пашалан `output/exp` папкаш `.safetensors` файлым воза: ошкыл дене `sigma`, `pc_error` (тудо яра аклымаш), `curvature`, нормы состояния, denoised да производный, радамлык, пытартыш латент да кӱлеш гын покшел латент радамым (`latent_stride`). Тӱҥ граф файл метаданныйыште аралалтеш.

`analyze_dumps.py` скрипт `log(pc_error)` дисперсийым ошкыл номер, cfg да конкрет образец дене умылтарыме ужашлалан пайла.

## Мо ыш ыште

Тергыме шотан ончыкталтеш, шоналтыме огыл.

- **Адаптивный ошкыл.** `budget` радам дене `apc_*` ошкыл-влакым яра ак дене угыч шеледа. Тудо икгай четлыкым кугу ойыртем дене эрта, но **штатный `normal` радамлыклан сеҥалтеш** (тудын рашлыкшын 0.81–0.99× ужашыже). Висыме йоҥылышым иктӧр пайлымаш дене ыштыме график-влакат `normal` деч начаррак улыт. Аклан (ablation) кодымо, продакшнлан огыл.
- **Йоҥылыш почеш йӱкым виктарымаш** (`response` ≠ 0). Чыла тергымаште саеммаш уке улмаш, тиде лач `eta`-м иземдыме семынак лектын. `response = 0.0` кодаш темлалтеш.
- **Паша cfg годым методын радамлыкше.** Cfg 1.0 годым 4-ше радаман метод euler-ым 1.30–1.52 гана сеҥа. Cfg 5.0 годым `dpmpp_2m` / `ipndm` / `deis` кокла гыч эн сайже 1.01–1.04× гына сеҥа, cfg 8.0 годым — пачаш ок сеҥе. Тӱҥ guidance кугыт годым кӱрмӧ йоҥылыш эн тӱҥ ужаш огыл.

## Вес сэмплер-влак нерген шонкалымаш

Тиде модель дене тергыме, пашаште кучылтмо деч ончыч палаш пайдале:

- `uni_pc` VP/eps-параметризацийлан петыралтын (`noise / sqrt(1 + sigma²)`, `model_type = "noise"`). Flow matching-лан тудо ок келше да cfg 8 годым euler-ын 0.63 акше ваштареш 6.86 пуа. Flux/SD3/Anima класс модель-влак дене кучылташ ок кӱл.
- Ик ошкыллан висыме NFE: `sa_solver`, `euler_ancestral`, `res_multistep_ancestral`, `dpmpp_3m_sde`, `er_sde`, `deis`, `clyb_4m_sde_momentumized` — 1.0. `heun`, `seeds_2`, `dpmpp_sde` — 1.9. `res_3s_ode` — 3.0, `res_5s_ode` — 5.0, `res_6s_ode` — 6.0. `dpm_adaptive` — 3.0. 8–14 NFE бюджет годым 1 NFE сэмплер-влакым гына таҥастараш йӧрӧ.
- 8 NFE годым кӱкшӧ радаман тӧрлатыше деч посна шуко ошкылан стохастик метод-влак пеш начарештыт: `res_multistep_ancestral` геометрий дене 1.93 пуа, а `clyb_4m_sde_momentumized` — 7.74 пуа (`sa_solver`-ын 0.40 улмыж ваштареш).

## Тергымаш-влак (Тесты)

Шкевуя пашам ыштат, GPU кӱлеш огыл:

```
python test_pc_core.py          # Адамсын негызше-влак, погынымаш радам, аклымашым калиброватлымаш
python test_adaptive_step.py    # линейный огыл стендыште адаптивный ваштареш статический радамлык-влак
```

ComfyUI йырвел кӱлеш, тудын вожшо гыч колтыза:

```
venv/Scripts/python.exe custom_nodes/adaptive-samplers/test_comfy_path.py   # NFE шотлымаш
venv/Scripts/python.exe custom_nodes/adaptive-samplers/test_stochastic.py   # sa_solver дене иктӧрлык
```

`test_pc_core.py` терга: Адамс предиктор ден корректор негыз-влак таблице дене 1e-16 марте келшат, верысе радамлык-влак 1–4 радамлан 2/3/4/5 улыт, да яра ак чын верысе йоҥылышым 0.93–0.98 медиан кыл дене эскера.

## Эксперимент скрипт-влак

`run_grid.py`, `run_schedule_ab.py`, `run_sde_test.py`, `run_jitter_sweep.py` ComfyUI дене HTTP API гоч виктарат, `probe_variance.json` графым шаблон семын кучылтыт. Лач нуно кӱшыл числа-влакым пуэныт; пайдаланыме деч ончыч шаблонышто модель, LoRA да VAE лӱм-влакым тӧрлатыза.
